## 從想做出東西開始

小四接觸 App Inventor 2，小五買了一本 C++ 的書開始自學，國中接觸 Java 後陸續把幾個 Android App 上架到 Google Play，到現在累積了上萬下載。

那時候沒有什麼「職涯規劃」，只是想把腦中的東西真的做出來。

## 高中：競賽與資安

高一加入竹中軟體研究社，正式開始學資料結構與演算法；高二當社長，開始參加各種程式競賽，也旁聽了清大的競技程式設計課程。

同一段時間因緣際會接觸資安，在 BugkuCTF 最高排到第 42 名。高三入選台灣好厲駭導師深度輔導模式，並以特殊選才錄取北科資工系。

## 大學：從選手到講者

- 2023 TUPC 全國科技大專校院程式競賽冠軍
- ICPC 2023、2024 台灣站銅獎
- 加入 Taiwan Kotlin User Group，開始站上社群講台
- 創立臺北科技大學駭客喵喵社

## 現在

目前就讀清華大學資訊工程博士班，在資訊安全實驗室 IS Lab 做研究，同時在 IBM 擔任 Associate Application Consultant Summer Intern。

寫程式這件事從興趣變成專業，但驅動力還是同一個：想知道它到底怎麼運作。
